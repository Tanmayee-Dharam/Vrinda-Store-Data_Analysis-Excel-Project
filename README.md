# Vrinda-Store-Data_Analysis-Excel-Project

# Project Objective
The goal of this project is to create a dashboard of annual sales data for a fictitious store called Vrinda Store for the year 2022. This dashboard aims to provide a visually appealing and intuitive interface to easily interpret key metrics and get new insights about the business in order to make data-driven decisions for improving sales for 2023

Note : All datasets and reports do not represent any institution comapny or country and is just a dummy dataset downloaded from Kaggel to demonstrate Excel capabilities.

# Tech Stack Used:
Advance Excel

# Skills showcased in this Project:
1. Data Cleaning, Data Transformation, Data Analysis
2. Filtering, Sorting and Conditional function.
3. Pivot Tables and Pivot Chart
4. Dashboard creation

# Questions (KPIs) that were explored in this project:
1. Compare the sales and orders using single chart.
2. Which month got the highest sales and orders?
3. Who purchased more - Men or Women?
4. What are different order status in 2022?
5. List top 10 states contributingto the sales?
6. Relation between age and gender based on number of orders.
7. Which Channel is contributing maximum to the sales?
8. Highest selling category?

# Process 
Data Cleaning and Transformation:
   This stage began with getting to know the dataset and checking for any data quality issues.
   1. Checking NULL values, blanks and Errors
   2. Removing duplicates, and irrelevant columns.
   3. Made sure data is consistent and clean with respect to data type, data format and values used.
   4. Creating 2 new attributes 'Age Group' and 'Month' were added for logical and easy interpretation of dataset.

Data Analysis:
  The dataset was summarized through the creation of six pivot tables to support the identification of key trends. These summaries focused on the correlation between sales and variables such as gender, order 
  volume across different months, and top-performing states. Furthermore, trends in order status, order distribution across various channels, and comparisons based on age were analyzed.

Data Visualization:
  Finally, the dashboard was created by inserting and customizing the pivot charts of corresponding pivot table. For user friendly and interactive experience 3 "Slicers" were added.

# Project Insight:
1. Women customers are more likely to buy products compared to men (~65%).
2. The states of Maharashtra, Karnataka and Uttar Pradesh are the top 3 product buyers.
3. The adult age group (30-49 yrs) is max contributing (~50%) and buys the most products.
4. The maximum number of products customer orders from Amazon, Flipkart and Myntra channels.

# Final Conclusion:
To increase sales at Vrinda Store, a focused marketing plan should target women between the ages of 30 and 49 who live in Maharashtra, Karnataka, and Uttar Pradesh. These women often shop online and have strong buying power. Showing them personalized ads, special offers, and discount coupons from popular sites like Amazon, Flipkart, and Myntra can help get their attention and encourage them to buy. The store can also boost results by using local preferences, promoting during festivals, and suggesting products that match their interests. This approach will help more people know about Vrinda Store and lead to better sales.
